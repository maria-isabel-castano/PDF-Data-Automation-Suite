# PDF & OCR Data Automation Suite

A professional Python solution for high-accuracy data extraction from digital and scanned PDF documents into structured Excel formats.

## 🎯 Project Overview
This tool eliminates manual data entry by automating the parsing of complex PDF documents. It combines native text extraction with OCR (Optical Character Recognition) to ensure no data is left behind, regardless of the source format.

## ✨ Key Features
- **Hybrid Extraction:** Uses `PyMuPDF` for digital text and `Tesseract OCR` for scans/images.
- **Automated Cleaning:** Integrated Regex layers to standardize dates, currency, and special characters.
- **Batch Processing:** Capable of handling multiple files in a single execution.
- **Excel Formatting:** Generates clean, ready-to-use `.xlsx` files.

## 🛠️ Technical Stack
- **Language:** Python 3.x
- **Libraries:** Pandas, PyMuPDF, Pytesseract, Pillow.
- **Workflow:** Data Extraction -> Cleaning & Validation -> Structured Export.

## ⚙️ Setup
1. Clone this repository.
2. Install dependencies:  
   `pip install -r requirements.txt`
3. Ensure **Tesseract OCR** is installed on your local system.
